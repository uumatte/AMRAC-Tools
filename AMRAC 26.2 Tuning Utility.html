AMRAC · Minecraft 26.2

AMRAC 26.2 Tuning Utility

Every aircraft and missile AMRAC ships, with their performance curves computed here from the same aerodynamics, engine and atmosphere the game runs — not read off a spec sheet. Drop an edited .json in below to compare it with the defaults before it goes into your config/amrac/flightmodel folder.

Load an aircraft, a missile or an environment. Drop .json here — a whole folder works too and is read recursively — comments and trailing commas are fine. The mod's defaults are built in. A dropped file whose id matches one already loaded replaces it in place, a new id joins them, and selecting several at once highlights the fields where they differ in the spec table.

environment.json is the exception: it adds no series but replaces the air everything else is measured in, so dropping one recomputes every curve on the page. Until you do, the built-in one is used — the byline says which is in force.
